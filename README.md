# آموزش مهندسی نرم‌افزار ۱

### معرفی پروژه

این مخزن با هدف انتشار آموزش‌ها، یادداشت‌ها و مثال‌های کاربردی در زمینه درس **مهندسی نرم‌افزار ۱** ایجاد شده است.

مطالب این مجموعه با تمرکز بر یادگیری مفاهیم پایه مهندسی نرم‌افزار، چرخه حیات توسعه نرم‌افزار، مدل‌های فرآیند، مهندسی نیازمندی‌ها، تحلیل و طراحی سیستم، معماری نرم‌افزار و تست تهیه می‌شوند.

### پیش‌نیازهای مطالعه

برای درک بهتر مطالب این مخزن، آشنایی مقدماتی با موارد زیر مفید است:

**۱. مفاهیم پایه برنامه‌نویسی**

- متغیرها، انواع داده و ساختارهای کنترلی
- توابع و رویه‌ها
- مفاهیم شیءگرایی (کلاس، شیء، وراثت، چندریختی)
- ساختار داده‌های پایه (آرایه، لیست، پشته، صف)

**۲. مفاهیم پایه پایگاه داده**

- مدل رابطه‌ای
- جداول، کلید اصلی و کلید خارجی
- دستورات پایه SQL

**۳. آشنایی با یک زبان برنامه‌نویسی شیءگرا**

- ترجیحاً C# یا Java
- آشنایی با محیط توسعه (IDE)
